# SPATIO-TEMPORAL-VIDEO-ANOMALY-DETECTION-SYSTEM-USING-PROPOSED-HYBRID-DEEP-LEARNING-MODELS 
# A deep learning system that detects anomalies in video streams by learning both spatial and temporal patterns using hybrid neural network architectures.
# Features
Video-based anomaly detection
Spatial and temporal feature learning
Suitable for surveillance scenarios
# Model Design
CNN for spatial feature extraction
LSTM for temporal sequence analysis
# Tech Stack
Python, OpenCV, TensorFlow / PyTorch, NumPy
